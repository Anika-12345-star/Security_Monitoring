# Security_Monitoring
Observe. Analyze. Detect. Defend. — Practical Security Monitoring Labs.


 📌 **About This Repository**

This repository documents my hands-on journey into Security Monitoring and Log Analysis.

It focuses on investigating Windows Security Event Logs using PowerShell to understand system activities, identify suspicious behavior, detect potential cyberattacks, and improve security monitoring skills.

Observe. Analyze. Detect. Defend.

🎯 **Lab Objectives**
* Analyze Windows Security Event Logs using PowerShell.
* Identify successful and failed login attempts.
* Extract and examine event properties.
* Detect potential brute-force attacks.
* Investigate lateral movement activities.
* Identify privilege escalation indicators.
* Automate security log analysis using PowerShell scripts.
* Generate security reports in CSV and HTML formats.

🛠 **Tools & Technologies**
* Windows 10/11
* Windows PowerShell 5.1+
* Windows Event Viewer
* Visual Studio Code (Optional)
